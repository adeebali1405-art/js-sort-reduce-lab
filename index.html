Quick syntax reference

Sort: low to high
products.sort((a, b) => a.price - b.price);
Sort: high to low
products.sort((a, b) => b.price - a.price);
Reduce: calculate a total
products.reduce((sum, product) => sum + product.price, 0);
Preserve the original array
[...products].sort((a, b) => a.price - b.price);

Practice tips

  • Use arrow functions wherever possible.
  • Understand the accumulator in reduce(): it carries the result from one item to the next.
  • sort() modifies the original array. Copy first with [...products].
  • Test every answer with console.log().
  • For text, sort with localeCompare() instead of subtracting.
